# Low-Level Design Lab

Repository for learning object-oriented design, design patterns, and practicing
low-level design interviews in Python.

## Structure

```text
learn/
├── 00. learn/          OOP, SOLID, and design-pattern exercises
└── 01. parking lot/    Guided Parking Lot implementation
practice/               Mock-interview implementations
```

## Run the Parking Lot tests

```bash
cd "learn/01. parking lot"
python3 -m unittest discover -v
```
